# 主要特性概览

## 9 大核心特性

1. **基于流的设计**：所有消息输出均为异步流式设计，支持实时响应
2. **Cookie 安全检测**：内置 Cookie 安全检测功能，保护会话安全
3. **供应商无关机制**：数据类型和对话管理独立于特定供应商，抽象为"模型适配器"接口，提供高可移植性
4. **MCP 客户端支持**：扩展机制中集成 MCP 客户端，增强系统扩展能力
5. **事件驱动架构**：完备的事件系统（由 AmritaSense 提供），配合运行时依赖注入机制，实现灵活响应式的智能体行为
6. **工具集成框架**：健壮的外部工具和服务集成系统
7. **高级记忆管理**：精细的上下文处理，支持自动上下文压缩和 Token 优化
8. **原生挂起/恢复支持**：内置机制（AmritaSense `SuspendObjectStream`），可在任意点暂停和恢复智能体执行流
9. **可组合工作流引擎**：由 [AmritaSense](https://sense.amritabot.com) 驱动——基于节点的执行，支持原生控制流（IF/WHILE/JUMP/TRY）、依赖注入和中间件

## 架构优势

AmritaCore 的架构以模块化为设计核心。各核心组件可独立使用或组合使用，从而实现：

- 针对特定场景的轻松定制
- 渐进式特性采用
- 降低组件间耦合
- 简化测试和维护

## 应用场景示例

**场景一：客服机器人**
可访问知识库、处理订单、将复杂问题升级给人工客服的机器人。

**场景二：研究助手**
可从多个来源收集信息、分析文档、综合报告的智能体。

**场景三：工作流自动化**
编排多种工具和服务以实现业务流程自动化的智能系统。

这些场景受益于 AmritaCore 的事件驱动架构、工具集成能力和稳健的记忆管理。
