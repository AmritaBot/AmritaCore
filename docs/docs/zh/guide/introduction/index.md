# 项目介绍

## 什么是 AmritaCore？

AmritaCore 是构建于 [AmritaSense](https://sense.amritabot.com) 之上的
**灵活渐进式 Agent 框架**——轻量、聚焦基础设施的 agent 运行时。

**AmritaCore = AmritaSense（工作流引擎 + 事件 + 流） + Agent 层（策略、会话、工具、MCP、适配器）。**

- **交互优先**：通过原生异步流式实现实时、响应式 agent 应用
- **轻量**：最小依赖、最大性能
- **供应商无关**：数据类型与对话管理独立于供应商
- **可扩展**：适配器、自定义工具、MCP 客户端、自定义 Tokenizer
- **安全感知**：内置 cookie 检测、注入感知默认

## 它不是什么

AmritaCore **不是** LangChain 或 LlamaIndex 式框架的替代品。它在成熟的工作流
引擎之上提供必要的构建模块——如果你需要开箱即用的链与集成，那些框架服务于
不同目的。

## 使命

提供轻量而强大的 agent 开发基础，优先简洁、性能与灵活——设计哲学见
[附录](../appendix.md)。
