# 项目介绍

## 项目概述

### 什么是 AmritaCore？

AmritaCore 是一个**基于 [AmritaSense](https://sense.amritabot.com) 的灵活渐进式 Agent 框架**。它利用 AmritaSense 的异步工作流引擎，提供可组合、高性能的智能体执行能力，开销极低。

**AmritaCore = AmritaSense（工作流引擎 + 事件 + 流） + Agent 层（策略、会话、工具、MCP、适配器）。**

**AmritaCore 以交互为优先设计**，通过 AmritaSense 的原生异步流式架构，实现实时、响应式的智能体应用。

可以将 AmritaCore 视为 AI 智能体的"操作系统"——提供核心原语和抽象，帮助构建健壮、生产就绪的智能体应用，而不增加重量级框架的负担。

**AmritaCore 并非 LangChain 或 LlamaIndex 等现有框架的替代品。**它是一个**轻量级、聚焦基础设施的 Agent 框架**，在成熟的工作流引擎之上提供必要的构建模块。

### 项目背景与使命

AmritaCore 的使命是为智能体开发提供轻量而强大的基础，优先关注简洁性、性能和灵活性。随着 AI 应用对实时响应和高效资源利用的需求日益增长，需要一个能够：

- 提供**基于流的设计**实现实时响应
- 通过内置 **Cookie 安全检测**确保安全性
- 保持**供应商无关**的方法，实现高可移植性
- 通过集成 MCP 客户端支持**可扩展性**
- 提供**最小依赖**和**最大性能**

AmritaCore 以聚焦的架构满足这些需求，在避免不必要复杂性的同时强调核心能力。

### 核心价值主张

- **基于 AmritaSense 构建**：利用经过实战检验的异步工作流引擎，支持可组合节点、依赖注入和原生控制流（IF/WHILE/JUMP/TRY）
- **基于流的设计**：所有消息输出设计为异步流，实现实时响应
- **轻量级架构**：最小依赖、最大性能，适用于资源受限环境
- **交互优先**：原生异步流式架构，针对实时响应式应用优化
- **基础设施级别**：为 AI 智能体提供关键的"操作系统"能力
- **安全性**：内置 Cookie 安全检测，确保会话安全
- **供应商无关**：数据类型和对话管理独立于特定供应商
- **可扩展性**：扩展机制中集成 MCP 客户端，增强系统扩展能力
